\# Sri Lanka Smart Todo - DevOps Project



\## Project Description



Sri Lanka Smart Todo is a simple web-based task management application developed as part of a DevOps assignment. The application allows users to add, complete, delete, and filter tasks.

\## Branching Strategy



The project follows a simple Git branching strategy:



\- `main` - Production-ready code

\- `develop` - Integration branch

\- `feature/todo-core` - Todo application development

\- `feature/devops-setup` - CI/CD configuration

\- `feature/project-improvements` - Project improvements and documentation



Feature branches are merged into `develop` using Pull Requests. The completed `develop` branch is then merged into `main`.



\## CI/CD



The project uses GitHub Actions for:



1\. Validating the project structure.

2\. Checking that required project files exist.

3\. Deploying the application using GitHub Pages.
