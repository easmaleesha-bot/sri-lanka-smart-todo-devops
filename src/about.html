About Smart Todo

Sri Lanka Smart Todo is a simple task management web application built as a DevOps Team Assignment.

About the Project

This application is designed to help users streamline their daily task management. It delivers an offline-first workspace to manage daily activities efficiently with zero third-party packages or server latency.

  • ✓ Daily task management
  • ✓ Add, complete and delete tasks
  • ✓ Filter tasks (All / Active / Completed)
  • ✓ Persistent data using browser localStorage
  • ✓ Real-time task metrics and dashboard statistics
  • ✓ Clean responsive design across devices

DevOps & Deployment

This assignment demonstrates an automated continuous integration and continuous deployment (CI/CD) workflow. The project manages branches strictly: develop is the main integration and testing branch, while main is the protected production branch automatically deployed to the live server.
